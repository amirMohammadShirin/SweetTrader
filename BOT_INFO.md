## Quick Start

1. **Get your bot token** from BotFather
2. **Create `.env` file**:
   ```bash
   cp .env.example .env
   ```
3. **Add your token to `.env`**:
   ```env
   TELEGRAM_BOT_TOKEN=your_token_here
   ```
4. **Add other required credentials** (MT5, etc.)
5. **Run the bot**:
   ```bash
   python bot.py
   ```

## Bot Customization

You can customize your bot using these BotFather commands:

- `/setdescription` - Set bot description
- `/setabouttext` - Set about section
- `/setuserpic` - Set profile picture
- `/setcommands` - Set command descriptions
